- Updated wxWidgets to 3.3.4.
- Added a Theme setting (System, Dark, Light) on systems that support it.
- Added an `--encoding` option to `fbide format`; otherwise the file encoding is detected the same way as in the editor.
- Fixed the formatter losing code in some cases (#136).
- Fixed various other formatting issues, including preprocessor directives written with spaces after `#` (#136).
- Fixed procedures that are both declared and defined appearing twice in the Sub / Function browser.
